# us-recon

少角度超声（Plane-Wave / Sparse-Angle）图像重建。

## 一句话问题

> 用深度学习从**少角度（低质）超声图像**重建出接近**多角度复合（高质）**的图像，
> 同时解决两个关键问题：**如何证明重建只去伪影、不损伤真组织**，以及**重建中亮点丢失的根因**。

## 目录结构

```
us-recon/
├─ configs/            # yaml 配置
├─ data/               # 数据读取、预处理、patch 切分
├─ models/             # 网络定义（UNet）
├─ losses/             # 损失函数
├─ metrics/            # PSNR/SSIM/CNR/gCNR/FWHM/点目标恢复率
├─ train.py            # 训练入口
├─ eval.py             # 评估入口（待补）
└─ requirements.txt
```

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 一键复现占位训练（随机张量数据）
python train.py --config configs/base.yaml
```

### 双轴证据表（自仿真点散射体，已知真点/伪影）

| 轴 | 指标 | 低质图 (K=1) | DL 重建 | 结论 |
|---|---|---|---|---|
| 抗伪影 | 消声区 CNR | 52.86 | **25379** | ✅ 伪影清除 |
| 抗伪影 | 消声区标准差 | 0.0162 | **0.0000** | ✅ 背景变干净 |
| 保组织 | 点1 恢复率 (z=12mm) | — | **1.000** | ✅ 保住 |
| 保组织 | 点2 恢复率 (z=25mm) | — | **1.032** | ✅ 保住 |
| 保组织 | 点3 恢复率 (z=34mm) | — | **0.898** | ⚠️ 丢 10% |

> **一句话诊断**：重建能有效去伪影，但对深部弱点（z=34mm）仍有约 10% 的亮点丢失，说明「抗伪影」与「保组织」存在权衡，深部弱点是下一步改进重点。
